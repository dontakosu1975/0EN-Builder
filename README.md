# 0EN Builder

**HTML/CSSを知らなくても始められ、使い込むほどWeb制作の自由度が広がるVisual Web Builder。**

0EN Builderは、Webサイトを作ったことがない人でも、説明書やHTML/CSSの事前学習なしで簡単なLPを作れることを目指すオープンなWeb制作ツールです。

利用者が操作するのは「文字の色」「大きさ」「位置」「背景」「余白」といった見たままの概念です。内部では0EN Builderがそれらを標準的なHTML/CSSへ変換します。

## コンセプト

> 初めて触った人を、コードで止めない。  
> 慣れた人を、簡単機能だけで止めない。

初心者にはCSSを意識させず、GUIだけでページを作れる体験を提供します。一方で、慣れてきた利用者には詳細設定やコード表示・編集へ段階的に進める余地を残します。

想定する操作レベルは次の3段階です。

- **かんたん** — 「文字を大きく」「中央に」「角を丸く」など、日常語で操作
- **詳細** — px、行間、余白などを具体的な値で調整
- **コード** — 生成されたHTML/CSSを確認・編集

## 基本思想

一般的なWeb BuilderのUI構造を参考に、基本画面は以下を想定しています。

- 左：追加できる要素・機能
- 中央：実際のページを確認するキャンバス／プレビュー
- 右：選択中の要素の設定

ただし、通常UIでは `font-size`、`padding`、`display:flex` といったCSS用語を第一言語にしません。

たとえば利用者が「文字を中央にする」と操作した場合、内部で `text-align:center` を生成します。「まわりを広げる」と操作すれば `padding` 等へ変換します。

**GUI操作 → 内部モデル → HTML/CSS → プレビュー**

という流れを基本にし、出力は可能な限り通常のHTML/CSSとします。0EN専用形式へのロックインを前提としません。

## PoC 01

最初からDIV、テーブル、複雑なカラム、ドラッグ＆ドロップ等には踏み込みません。

まずは「CSSという垣根をGUIで消せるか」を検証します。

初期PoCでは、文字や基本要素に対して以下をGUIから操作し、即時プレビューとHTML/CSS出力を行えることを目標とします。

- 内容の編集
- 文字色
- 背景色
- 文字サイズ
- 太字
- 左寄せ／中央／右寄せ
- 行間
- 余白
- 幅
- 枠線
- 角の丸み

PoCの成功条件は「Web制作経験のない人が、HTML/CSSを意識せず、説明書なしで簡単なLPを作れること」です。

## 将来構想

PoCで基本操作を検証した後、段階的に以下へ拡張します。

1. 画像・ボタン・区切りなどの基本要素
2. 複数要素の配置・並べ替え
3. DIV／セクション／囲み
4. Flex／横並び／2列・3列レイアウト
5. レスポンシブ設定
6. 複数ページ
7. 共通スタイル／サイト全体CSS
8. iframe・フォーム・動画・地図などの埋め込み
9. より高度なHTML/CSS表現

将来的にはScratchのように「できることを組み合わせる」感覚も取り入れます。ただし、プログラミング言語そのものを視覚化するのではなく、Webページの構造・配置・装飾を視覚的に組み立てられる方向を目指します。

## 開発方針

初期段階は大規模なWeb Builderエンジンを前提とせず、小さなPoCから検証します。必要になった段階で既存OSSの採用・組み込み・改造も検討します。

既存OSSを利用する場合は、そのライセンス条件に従います。0EN Builder自体はGitHub上で公開し、改造・再配布可能な形で開発を進める方針です。
